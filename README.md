# Learning Python

A small Python project for practicing concepts from the freeCodeCamp Python course.

## Get started

Use Python 3.9 or newer. From the project directory, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

Run the starter program:

```bash
python -m learning_python
```

Run the tests:

```bash
python -m unittest discover -s tests
```
